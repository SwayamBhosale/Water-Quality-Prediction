# Water Quality Monitoring and Prediction

A machine learning project to predict water potability based on physical and chemical properties of water samples.

---

## Overview

This project uses various machine learning algorithms to predict water quality. It includes data preprocessing, exploratory data analysis (EDA), and model evaluation.

---

## Dataset

- **Name**: `water_potability.csv`  
- **Description**: Features include pH, Hardness, Solids, Chloramines, and more, with a target label indicating potability.

---

## Technologies Used

- **Libraries**: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, SMOTE, XGBoost, LightGBM, CatBoost  
- **Algorithms**: Random Forest, Logistic Regression, Gradient Boosting, SVM, KNN, Naive Bayes, and more  
- **Techniques**: GridSearchCV, RandomizedSearchCV, RepeatedStratifiedKFold, ConfusionMatrixDisplay
